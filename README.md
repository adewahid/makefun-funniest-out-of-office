A make.fun entry for **The Funniest Out-of-Office** — one line, at most 140 characters: the funniest out-of-office auto-reply a real person would actually set.

## The line

> I'm out of office — I left my inbox with my toddler, who has replied to everyone with 'no'. Honestly, an improvement.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt`.
